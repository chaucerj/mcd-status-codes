# 状态码全表（语义参考）

> 规则版本 RULES_VERSION 3.0 · 本表由 `scripts/codes.py`（单一事实源）生成。
> 冲突时以 codes.py 为准。方向：ingest = 摄入方向（你发起），probe = 探活方向（运维 Agent 发起）。

## ingest 摄入方向（14 码）

### 200 OK — 摄入已入账 `ingest`
- **定义**：你的身体正常受理了这次摄入，并完成记账
- **证据**：全部商品热量可计算，且在单餐配额内

### 201 Created — 新资源入库 `ingest`
- **定义**：你吃到了历史上从未出现过的单品，身体新建了一条记录
- **证据**：该品名在此前全部订单中均未出现过

### 206 Partial Content — 摄入无法完整计量 `ingest`
- **定义**：你的身体账本里查不全这次摄入，返回的是残缺甚至空的响应
- **证据**：部分（0/N 至 N-1/N）商品无法在营养账本中定位

### 301 Moved Permanently — 取餐渠道永久改道 `ingest`
- **定义**：你的取餐路径换了节点，并已永久指向新渠道
- **证据**：本次取餐方式与上一单不同

### 304 Not Modified — 缓存命中 `ingest`
- **定义**：这次摄入与上一单完全一致，身体直接复用了上次的响应
- **证据**：商品组合与份数同上一单逐项相同

### 403 Forbidden — 营养署拒绝放行 `ingest`
- **定义**：你的热量或钠超出单餐配额，身体的准入网关拦下了这单
- **证据**：超出单餐 800 kcal 或 1200 mg 钠阈值

### 404 Not Found — 订单不存在 `ingest`
- **定义**：你的身体服务上还没有任何订单资源，这一单查无此物
- **证据**：初始拉取时订单集合为空，或该订单从未存在

### 408 Request Timeout — 请求超时 `ingest`
- **定义**：你在深夜发起摄入请求，但身体已不在服务时段
- **证据**：下单时间落在 22:00–04:59

### 418 I'm a teapot — 我是茶壶 `ingest`
- **定义**：你只点了饮料，请求打到了茶壶而不是餐桌
- **证据**：整单商品均为饮品

### 429 Too Many Requests — 摄入请求过频 `ingest`
- **定义**：你在同一天发起了多次摄入，身体对你限流
- **证据**：当日第 2 单及以后

### 500 Internal Server Error — 系统过载 `ingest`
- **定义**：单餐热量超出身体的处理能力，服务当场过载
- **证据**：单餐热量 > 1500 kcal

### 502 Bad Gateway — 聚合网关 `ingest`
- **定义**：这一次请求聚合了多个子请求，单次摄入量过大
- **证据**：单笔商品总件数 ≥ 6

### 503 Service Unavailable — 身体服务宕机 `ingest`
- **定义**：这一天你的身体服务完全没有响应
- **证据**：当日零订单，计入 Uptime 分母

### 504 Gateway Timeout — 上游中止 `ingest`
- **定义**：这次摄入最终没有发生，链路在上游超时中止
- **证据**：订单状态为已取消

## probe 探活方向（6 码，v3.0 新增）

### 103 Early Hints — 补给建议下发 `probe`
- **定义**：你的运维 Agent 在你发起摄入之前，依据你的代谢曲线提前给出补给提示
- **证据**：当日已摄入与分餐预算存在缺口，且探活窗口开启

### 204 No Content — 主动静默 `probe`
- **定义**：你的运维 Agent 探活后确认本窗口无需任何摄入，正确地保持了沉默
- **证据**：当日摄入与预算吻合，无缺口可补

### 412 Precondition Failed — 建议被目标否决 `probe`
- **定义**：你的运维 Agent 收回了一条与你声明目标冲突的补给建议
- **证据**：建议内容与 prefs.json 中 goals（热量/钠/预算上限）矛盾

### 425 Too Early — 过早打扰判定 `probe`
- **定义**：你的运维 Agent 判定此刻探活为时过早，主动推迟了这次提醒
- **证据**：前一晚存在 408 深夜摄入，晨间窗口按规则顺延

### 599 Network Timeout — 建议窗口超时 `probe`
- **定义**：你的运维 Agent 在补给窗口内给出的建议直到窗口关闭都未被你采纳
- **证据**：窗口期内无对应摄入请求，也无忽略反馈

### 522 Connection Timed Out — 连续窗口失联 `probe`
- **定义**：你的运维 Agent 连续多个探活窗口与你完全失去联系，升级了告警级别
- **证据**：连续 2 个窗口既无采纳也无忽略反馈
